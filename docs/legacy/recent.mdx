:::warning

此接口属于遗留接口，不推荐在新业务中使用，可能随时发生中断且不会收到维护通知。

此接口已不会再添加任何新字段。

请使用[查询近期活动](/docs/活动/list-recent-open-events) 或 [查询活动列表](/docs/活动/list-open-events) 接口替代。

:::

:::info

无需携带鉴权信息。

:::

:::tip

展会宣传图片可能较大，请根据实际需求缓存、裁剪并优化体积。

:::

调用此接口可以获取最近 30 天内的展会信息。

## 查询参数

<ParamField query="keep_old" type="string" placeholder="true">
  当此值为 `true` 时，如果最近 30 天内没有数据，会返回过期的最后一条数据。
</ParamField>

```
https://api.furrycons.cn/event/recent
```

## 迁移至新版

新版接口为 `/open/event/recent`，需要携带免费申请的应用令牌，鉴权格式为 `Authorization: Bearer <token>`。将参数 `keep_old` 改为 `keepOld`，并根据[新版接口文档](/docs/活动/list-recent-open-events)更新响应字段映射。
